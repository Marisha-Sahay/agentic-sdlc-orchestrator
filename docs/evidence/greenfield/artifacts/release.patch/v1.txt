+# URL Shortener API
+
+A plain-English guide to the API: what each endpoint does, what to send, and every response you
+can get back. The examples were captured from the running service, except the two `500`
+responses, which can't be triggered on demand and are shown as the code produces them.
+
+- **Base URL:** `http://localhost:8080` when you run it locally.
+- **Format:** JSON in, JSON out. Send `Content-Type: application/json` when you post a body.
+- **Errors:** every error has the same shape; see [Errors](#errors).
+- **Try it:** start the service and open <http://localhost:8080/swagger-ui.html>.
+- **Formal contract:** [`api/openapi.yaml`](api/openapi.yaml) is the machine-readable version of
+  this guide. If the two ever disagree, the contract wins.
+
+## Endpoints at a glance
+
+| Endpoint | What it does | Success | Errors you might see |
+|---|---|---|---|
+| `POST /api/v1/links` | Create a short link | `201` | `400`, `409`, `415`, `429`, `500` |
+| `GET /api/v1/links/{code}` | Look up a link | `200` | `404` |
+| `DELETE /api/v1/links/{code}` | Delete a link | `204` | `404` |
+| `GET /{code}` | Follow a short link | `302` | `404`, `410` |
+
+On top of these, a wrong HTTP method gets `405`, an `Accept` header that rules out JSON gets
+`406`, and an unexpected failure gets `500`; see
+[Responses any endpoint can give](#responses-any-endpoint-can-give). The operational endpoints
+(`/actuator/health`, `/actuator/info`, `/actuator/metrics`) are for operators and are not covered
+here.
+
+## Errors
+
+When something goes wrong you get a problem document
+([RFC 9457](https://www.rfc-editor.org/rfc/rfc9457)) with
+`Content-Type: application/problem+json`:
+
+```json
+{
+  "detail": "No link exists for code 'nope1234'",
+  "instance": "/nope1234",
+  "status": 404,
+  "title": "Link not found"
+}
+```
+
+- `title` is a short summary that doesn't change between requests, so code can match on it.
+- `detail` explains this particular failure.
+- `status` repeats the HTTP status, and `instance` is the path you called.
+- `errors` appears only on `400 Invalid request` and lists each field that was wrong.
+

+## 1. Create a short link
+
+`POST /api/v1/links`
+
+| Field | Required | What it is |
+|---|---|---|
+| `url` | yes | The long URL. Must be an absolute `http` or `https` URL of at most 2048 characters. Spaces around it are trimmed. |
+| `customAlias` | no | Your own code instead of a random one: 4 to 32 letters, digits, `_` or `-`. |
+| `expiresAt` | no | When the link stops working, as a future ISO-8601 time such as `2026-12-31T23:59:59Z`. Leave it out and the link never expires. |
+
+Without `customAlias` you get a random 7-character code such as `caMHkPU`. Codes are
+case-sensitive.
+
+```bash
+curl -i -X POST http://localhost:8080/api/v1/links \
+  -H 'Content-Type: application/json' \
+  -d '{"url": "https://example.com/some/long/path"}'
+```
+
+### 201 Created
+
+The link is ready. The `Location` header points at the link's details
+(`Location: http://localhost:8080/api/v1/links/caMHkPU`), and `shortUrl` is the link to share.
+
+```json
+{
+  "code": "caMHkPU",
+  "shortUrl": "http://localhost:8080/caMHkPU",
+  "targetUrl": "https://example.com/some/long/path",
+  "createdAt": "2026-10-29T04:53:05.128029Z",
+  "expiresAt": null
+}
+```
+
+With your own alias and an expiry:
+
+```json
+{
+  "url": "https://example.com/launch",
+  "customAlias": "launch-2026",
+  "expiresAt": "2026-12-31T23:59:59Z"
+}
+```
+
+Response `201`, `Location: http://localhost:8080/api/v1/links/launch-2026`:
+
+```json
+{
+  "code": "launch-2026",
+  "shortUrl": "http://localhost:8080/launch-2026",
+  "targetUrl": "https://example.com/launch",
+  "createdAt": "2026-10-29T04:53:05.188742Z",
+  "expiresAt": "2026-12-31T23:59:59Z"
+}
+```
+
+All times are UTC. `expiresAt` is `null` for a link that never expires.
+
+### 400 Bad Request: the request breaks a rule
+
+The title is `Invalid request` and `errors` says which field is wrong and why:
+
+```json
+{
+  "detail": "url must not contain user info",
+  "instance": "/api/v1/links",
+  "status": 400,
+  "title": "Invalid request",
+  "errors": [
+    {
+      "field": "url",
+      "message": "must not contain user info"
+    }
+  ]
+}
+```
+
+Every reason you can get:
+
+| You sent | `field` | `message` |
+|---|---|---|
+| No `url`, or only spaces | `url` | `must not be blank` |
+| A URL that isn't absolute `http`/`https`, e.g. `ftp://example.com/file` or `/just/a/path` | `url` | `must be an absolute http or https URL` |
+| A URL with user info, e.g. `https://bank.com@evil.com` (it really goes to `evil.com`) | `url` | `must not contain user info` |
+| A URL that points back at the shortener itself | `url` | `must not point at this shortener` |
+| A URL longer than 2048 characters | `url` | `must be at most 2048 characters` |
+| An alias that is too short, too long, or has other characters | `customAlias` | `must be 4-32 characters of letters, digits, '_' or '-'` |
+| A reserved alias (list below) | `customAlias` | `is a reserved word` |
+| An `expiresAt` in the past | `expiresAt` | `must be in the future` |
+
+For a missing or blank `url` the `detail` is `Request validation failed`; for the others it is the
+field and message together, as in the example above.
+
+Reserved aliases, in any letter case: `api`, `actuator`, `health`, `admin`, `static`, `assets`,
+`public`, `login`, `logout`, `error`, `favicon`, `robots`, `metrics`, `info`, `docs`, `swagger`,
+`openapi`, `www`. They would clash with the service's own pages.
+
+**Broken JSON or a value of the wrong type.** If the body isn't valid JSON, or a value can't be
+read (for example `"expiresAt": "tomorrow"`), you get a plainer 400 with no `errors` list:
+
+```json
+{
+  "detail": "Failed to read request",
+  "instance": "/api/v1/links",
+  "status": 400,
+  "title": "Bad Request"
+}
+```
+
+### 409 Conflict: the alias is taken
+
+That alias is already in use. This includes deleted links: a code is never handed out twice, so a
+deleted link's alias stays taken.
+
+```json
+{
+  "detail": "The alias 'launch-2026' is already in use",
+  "instance": "/api/v1/links",
+  "status": 409,
+  "title": "Alias already in use"
+}
+```
+
+### 415 Unsupported Media Type
+
+The body wasn't sent as JSON (the `Content-Type` header is missing or wrong).
+
+```json
+{
+  "detail": "Content-Type 'text/plain' is not supported.",
+  "instance": "/api/v1/links",
+  "status": 415,
+  "title": "Unsupported Media Type"
+}
+```
+
+### 429 Too Many Requests
+
+Each client (by IP address) can create 20 links a minute. The allowance refills gradually, about
+one request every 3 seconds, and the `Retry-After` header says how many seconds to wait
+(`Retry-After: 3`). Only creating links is limited; following and looking up links are not.
+
+```json
+{
+  "detail": "Rate limit exceeded; retry after 3 seconds",
+  "instance": "/api/v1/links",
+  "status": 429,
+  "title": "Too many requests"
+}
+```
+
+### 500 Internal Server Error
+
+Rare. One case is specific to this endpoint: the service tried 5 random codes and every one was
+already taken. With about 3.5 trillion possible codes this practically never happens, but if it
+does, simply try again.
+
+```json
+{
+  "detail": "Could not generate a unique short code after 5 attempts",
+  "instance": "/api/v1/links",
+  "status": 500,
+  "title": "Short code generation failed"
+}
+```
+
+Any other failure is the general 500 described under
+[Responses any endpoint can give](#responses-any-endpoint-can-give).
+

+## 3. Delete a link
+
+`DELETE /api/v1/links/{code}`
+
+```bash
+curl -i -X DELETE http://localhost:8080/api/v1/links/old-page
+```
+
+### 204 No Content
+
+Deleted, with an empty body. The link stops working at once, and its code is never reused.
+
+### 404 Not Found
+
+There is no such link, or it was already deleted (deleting twice gives `404` the second time).
+
+```json
+{
+  "detail": "No link exists for code 'old-page'",
+  "instance": "/api/v1/links/old-page",
+  "status": 404,
+  "title": "Link not found"
+}
+```
+

+## 4. Follow a short link
+
+`GET /{code}`. This is the link you share, for example `http://localhost:8080/launch-2026`.
+
+```bash
+curl -i http://localhost:8080/launch-2026
+```
+
+### 302 Found
+
+No body; the browser goes straight to the address in `Location`:
+
+```text
+Location: https://example.com/launch
+Cache-Control: no-store
+```
+
+Why 302 and not 301: browsers keep a 301 forever and stop asking the service, so deleting or
+expiring the link would have no effect. `Cache-Control: no-store` makes sure every visit checks in.
+
+Swagger UI can't show this response. The browser follows the redirect by itself and usually
+reports "Failed to fetch" because the target site blocks cross-site requests. Open the short link
+in a new tab, or use `curl -i`, instead.
+
+### 404 Not Found
+
+The link never existed or was deleted.
+
+```json
+{
+  "detail": "No link exists for code 'nope1234'",
+  "instance": "/nope1234",
+  "status": 404,
+  "title": "Link not found"
+}
+```
+
+A path that can't be a code at all (shorter than 4 or longer than 32 characters, or containing
+other characters such as `.`) also gets a 404, with the generic title `Not Found`:
+
+```json
+{
+  "detail": "No static resource abc.",
+  "instance": "/abc",
+  "status": 404,
+  "title": "Not Found"
+}
+```
+
+### 410 Gone
+
+The link has expired.
+
+```json
+{
+  "detail": "The link for code 'flash-sale' has expired",
+  "instance": "/flash-sale",
+  "status": 410,
+  "title": "Link expired"
+}
+```
+
+> **Known issue #1:** a link that was followed before it expired can keep redirecting for up to
+> 10 minutes after `expiresAt`, because the redirect cache doesn't re-check the expiry. The
+> [brownfield scenario](../docs/scenarios/brownfield.md) fixes this.
+

+## Responses any endpoint can give
+
+### 405 Method Not Allowed
+
+The path exists but not with that method, for example `PUT /api/v1/links/launch-2026`. The
+`Allow` header lists the methods that work (`Allow: GET, DELETE`).
+
+```json
+{
+  "detail": "Method 'PUT' is not supported.",
+  "instance": "/api/v1/links/launch-2026",
+  "status": 405,
+  "title": "Method Not Allowed"
+}
+```
+
+### 406 Not Acceptable
+
+You asked an endpoint that returns JSON (creating or looking up a link) for something else, for
+example with `Accept: text/plain`.
+
+```json
+{
+  "detail": "Acceptable representations: [application/json].",
+  "instance": "/api/v1/links/launch-2026",
+  "status": 406,
+  "title": "Not Acceptable"
+}
+```
+
+### 500 Internal Server Error
+
+Something unexpected broke. The details go to the server log, never into the response.
+
+```json
+{
+  "detail": "An unexpected error occurred",
+  "instance": "/api/v1/links",
+  "status": 500,
+  "title": "Internal server error"
+}
+```

+## Design notes
+
+- **302, not 301.** A 301 is cached by browsers indefinitely, so later visits would never reach
+  the service; that breaks deletion, expiry and any future click analytics. Redirects also send
+  `Cache-Control: no-store`.
+- **Random base62 codes.** `RandomBase62CodeGenerator` draws 7 characters from `SecureRandom`
+  (62^7, about 3.5 * 10^12 codes): not enumerable, no coordination between instances. The
+  database unique constraint is the source of truth: inserts use
+  `ON CONFLICT (code) DO NOTHING` and a collision is retried with a fresh code up to 5 times,
+  then fails with a 500 (`CodeGenerationException`). No exceptions drive the control flow, and a
+  collision cannot abort a surrounding transaction.
+- **Custom aliases** must match `^[A-Za-z0-9_-]{4,32}$` (the same pattern the redirect route
+  accepts) and must not be a reserved word (`api`, `actuator`, `health`, `admin`, `static`, ...).
+  A taken alias returns 409.
+- **Soft delete.** `DELETE` sets `deleted_at`; the row keeps its code, so a code is never reused
+  (re-creating the alias returns 409). The redirect cache entry is evicted on delete.
+- **Redirect cache.** `LinkResolver` keeps a Caffeine cache of `code -> target URL` (TTL and size
+  configurable, statistics exported as `cache.*` metrics). On a miss it loads the link from the
+  database and applies the not-found and expiry checks; unknown codes are not cached.
+- **Rate limiting.** A hand-rolled per-client token bucket (`RateLimiter`) on
+  `POST /api/v1/links` only, applied by a Spring MVC interceptor so rejections are rendered by
+  the same ProblemDetail advice (429 + `Retry-After`). Refill uses exact integer arithmetic on
+  an injected `Clock`. Buckets live in a size-bounded Caffeine cache that expires idle buckets
+  after one period, which loses nothing because such a bucket would be full again anyway. The
+  limit is per instance; several instances would need a shared store.
+- **Target URL policy.** Only absolute `http`/`https` URLs with a host, at most 2048 characters;
+  URLs with user info are rejected (`https://bank.com@evil.com` actually goes to `evil.com`), and
+  so are URLs pointing at the shortener's own host (redirect loops).
+- **Time** comes from an injected `java.time.Clock` everywhere, so tests control it. Timestamps
+  are stored as `timestamptz` at microsecond precision.
+

+package io.github.marishasahay.shortener.link;
+
+import java.util.Locale;
+import java.util.Set;
+import java.util.regex.Pattern;
+
+/**
+ * Validates client-chosen custom aliases: URL-safe characters only, a bounded length that matches
+ * the redirect route, and no reserved words that could be confused with application paths.
+ */
+public class AliasPolicy {
+
+  static final String FIELD = "customAlias";
+  static final Pattern ALIAS_PATTERN = Pattern.compile("^[A-Za-z0-9_-]{4,32}$");
+
+  static final Set<String> RESERVED_WORDS = Set.of(
+      "api", "actuator", "health", "admin", "static", "assets", "public", "login", "logout",
+      "error", "favicon", "robots", "metrics", "info", "docs", "swagger", "openapi", "www");
+
+  /**
+   * Validates an alias.
+   *
+   * @param alias the alias submitted by the client
+   * @throws InvalidLinkRequestException if the alias is malformed or reserved
+   */
+  public void validate(String alias) {
+    if (alias == null || !ALIAS_PATTERN.matcher(alias).matches()) {
+      throw new InvalidLinkRequestException(FIELD,
+          "must be 4-32 characters of letters, digits, '_' or '-'");
+    }
+    if (RESERVED_WORDS.contains(alias.toLowerCase(Locale.ROOT))) {
+      throw new InvalidLinkRequestException(FIELD, "is a reserved word");
+    }
+  }
+}

+import java.sql.ResultSet;
+import java.sql.SQLException;
+import java.sql.Types;
+import java.time.Instant;
+import java.time.OffsetDateTime;

+import org.springframework.stereotype.Repository;

+/**
+ * Explicit-SQL persistence for {@link Link}s. Deleted links are soft-deleted and invisible to
+ * lookups, but their codes stay in the table so they are never reused.
+ */
+@Repository
+public class LinkRepository {
+
+  private static final String INSERT_SQL = """
+      insert into links (code, target_url, created_at, expires_at)
+      values (:code, :targetUrl, :createdAt, :expiresAt)
+      on conflict (code) do nothing
+      returning id
+      """;
+
+  private static final String FIND_ACTIVE_SQL = """
+      select id, code, target_url, created_at, expires_at
+        from links
+       where code = :code
+         and deleted_at is null
+      """;
+
+  private static final String SOFT_DELETE_SQL = """
+      update links
+         set deleted_at = :deletedAt
+       where code = :code
+         and deleted_at is null
+      """;
+
+  private final JdbcClient jdbcClient;
+
+  public LinkRepository(JdbcClient jdbcClient) {
+    this.jdbcClient = jdbcClient;
+  }
+
+  /**
+   * Inserts a link unless its code is already taken (including by a deleted link).
+   *
+   * @param code the short code
+   * @param targetUrl the validated target URL
+   * @param createdAt creation instant
+   * @param expiresAt optional expiry instant
+   * @return the inserted link, or empty if the code already exists
+   */
+  public Optional<Link> insertIfAbsent(String code, String targetUrl, Instant createdAt,
+      Instant expiresAt) {
+    return jdbcClient.sql(INSERT_SQL)
+        .param("code", code)
+        .param("targetUrl", targetUrl)
+        .param("createdAt", timestamp(createdAt))
+        .param("expiresAt", timestamp(expiresAt))
+        .query(Long.class)
+        .optional()
+        .map(id -> new Link(id, code, targetUrl, createdAt, expiresAt));
+  }
+
+  /**
+   * Finds a link that has not been deleted. Expired links are returned.
+   *
+   * @param code the short code
+   * @return the link, or empty if it does not exist or was deleted
+   */
+  public Optional<Link> findActiveByCode(String code) {
+    return jdbcClient.sql(FIND_ACTIVE_SQL)
+        .param("code", code)
+        .query(LinkRepository::mapRow)
+        .optional();
+  }
+
+  /**
+   * Soft-deletes a link.
+   *
+   * @param code the short code
+   * @param deletedAt deletion instant
+   * @return {@code true} if an active link was deleted
+   */
+  public boolean softDelete(String code, Instant deletedAt) {
+    int updated = jdbcClient.sql(SOFT_DELETE_SQL)
+        .param("code", code)
+        .param("deletedAt", timestamp(deletedAt))
+        .update();
+    return updated > 0;
+  }
+

+    OffsetDateTime value = instant == null ? null : instant.atOffset(ZoneOffset.UTC);
+    return new SqlParameterValue(Types.TIMESTAMP_WITH_TIMEZONE, value);
+  }
+

+    return new Link(
+        rs.getLong("id"),
+        rs.getString("code"),
+        rs.getString("target_url"),

+  }
+

+    return value == null ? null : value.toInstant();
+  }

+import java.time.Clock;
+import java.time.Instant;

+/**
+ * Link lifecycle: create (with generated code or custom alias), read metadata, soft delete.
+ */
+@Service
+public class LinkService {
+
+  static final int MAX_CODE_ATTEMPTS = 5;
+  static final String EXPIRES_AT_FIELD = "expiresAt";
+
+  private static final Logger LOG = LoggerFactory.getLogger(LinkService.class);
+
+  private final LinkRepository repository;
+  private final CodeGenerator codeGenerator;
+  private final TargetUrlPolicy targetUrlPolicy;
+  private final AliasPolicy aliasPolicy;
+  private final LinkResolver linkResolver;
+  private final Clock clock;
+
+  /**
+   * Creates the service.
+   *
+   * @param repository link persistence
+   * @param codeGenerator generator for random codes
+   * @param targetUrlPolicy target URL rules
+   * @param aliasPolicy custom alias rules
+   * @param linkResolver redirect resolver whose cache is evicted on delete
+   * @param clock time source
+   */
+  public LinkService(LinkRepository repository, CodeGenerator codeGenerator,
+      TargetUrlPolicy targetUrlPolicy, AliasPolicy aliasPolicy, LinkResolver linkResolver,
+      Clock clock) {
+    this.repository = repository;
+    this.codeGenerator = codeGenerator;
+    this.targetUrlPolicy = targetUrlPolicy;
+    this.aliasPolicy = aliasPolicy;
+    this.linkResolver = linkResolver;
+    this.clock = clock;
+  }
+
+  /**
+   * Creates a short link.
+   *
+   * @param url the target URL
+   * @param customAlias optional alias to use as the code; {@code null} generates a code
+   * @param expiresAt optional expiry, must be in the future
+   * @return the created link
+   * @throws InvalidLinkRequestException if the URL, alias or expiry is invalid
+   * @throws AliasAlreadyExistsException if the alias is taken
+   * @throws CodeGenerationException if no unique code could be generated
+   */
+  public Link create(String url, String customAlias, Instant expiresAt) {
+    String targetUrl = targetUrlPolicy.validate(url);
+    Instant now = clock.instant().truncatedTo(ChronoUnit.MICROS);
+    Instant expiry = expiresAt == null ? null : expiresAt.truncatedTo(ChronoUnit.MICROS);
+    if (expiry != null && !expiry.isAfter(now)) {
+      throw new InvalidLinkRequestException(EXPIRES_AT_FIELD, "must be in the future");
+    }
+    if (customAlias != null) {
+      aliasPolicy.validate(customAlias);
+      return repository.insertIfAbsent(customAlias, targetUrl, now, expiry)
+          .orElseThrow(() -> new AliasAlreadyExistsException(customAlias));
+    }
+    return insertWithGeneratedCode(targetUrl, now, expiry);
+  }
+
+  /**
+   * Returns the metadata of an active (not deleted) link; expired links are still returned.
+   *
+   * @param code the short code
+   * @return the link
+   * @throws LinkNotFoundException if no active link exists for the code
+   */
+  public Link get(String code) {
+    return repository.findActiveByCode(code)
+        .orElseThrow(() -> new LinkNotFoundException(code));
+  }
+
+  /**
+   * Soft-deletes a link and evicts it from the redirect cache. The code is never reused.
+   *
+   * @param code the short code
+   * @throws LinkNotFoundException if no active link exists for the code
+   */
+  public void delete(String code) {
+    boolean deleted = repository.softDelete(code, clock.instant().truncatedTo(ChronoUnit.MICROS));
+    linkResolver.evict(code);
+    if (!deleted) {
+      throw new LinkNotFoundException(code);
+    }
+  }
+
+  private Link insertWithGeneratedCode(String targetUrl, Instant now, Instant expiry) {
+    for (int attempt = 1; attempt <= MAX_CODE_ATTEMPTS; attempt++) {
+      String code = codeGenerator.generate();
+      Optional<Link> inserted = repository.insertIfAbsent(code, targetUrl, now, expiry);
+      if (inserted.isPresent()) {
+        return inserted.get();
+      }

+          MAX_CODE_ATTEMPTS);
+    }
+    LOG.error("Exhausted {} attempts to generate a unique code", MAX_CODE_ATTEMPTS);
+    throw new CodeGenerationException(MAX_CODE_ATTEMPTS);
+  }

+package io.github.marishasahay.shortener.link;

+import java.util.random.RandomGenerator;
+
+/**
+ * Generates fixed-length codes from the base62 alphabet using a (secure) random source. Codes are
+ * not enumerable and need no coordination between instances; with 62^7 (about 3.5 * 10^12)
+ * possible 7-character codes, collisions are rare and handled by a retry on insert.
+ */
+public class RandomBase62CodeGenerator implements CodeGenerator {
+
+  static final String ALPHABET = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz";
+
+  private final RandomGenerator random;
+  private final int length;
+
+  /**
+   * Creates a generator.
+   *
+   * @param random the random source; production uses {@link java.security.SecureRandom}
+   * @param length the code length, at least 1
+   */
+  public RandomBase62CodeGenerator(RandomGenerator random, int length) {
+    if (length < 1) {
+      throw new IllegalArgumentException("length must be positive, was " + length);
+    }
+    this.random = random;
+    this.length = length;
+  }
+
+  @Override
+  public String generate() {
+    StringBuilder code = new StringBuilder(length);
+    for (int i = 0; i < length; i++) {
+      code.append(ALPHABET.charAt(random.nextInt(ALPHABET.length())));
+    }
+    return code.toString();
+  }

+package io.github.marishasahay.shortener.link;
+
+import java.net.URI;
+import java.net.URISyntaxException;
+import java.util.Locale;
+import java.util.Set;
+
+/**
+ * Decides which target URLs may be shortened.
+ *
+ * <p>Only absolute {@code http}/{@code https} URLs with a host are accepted. URLs carrying
+ * user-info are rejected because {@code https://bank.com@evil.com} visually suggests the wrong
+ * host, and URLs pointing at the shortener itself are rejected to prevent redirect loops.
+ */
+public class TargetUrlPolicy {
+
+  static final int MAX_LENGTH = 2048;
+  static final String FIELD = "url";
+
+  private static final Set<String> ALLOWED_SCHEMES = Set.of("http", "https");
+
+  private final String ownHost;
+
+  /**
+   * Creates the policy.
+   *
+   * @param ownHost the shortener's own public host, rejected as a target; may be {@code null}
+   */
+  public TargetUrlPolicy(String ownHost) {
+    this.ownHost = ownHost == null ? null : ownHost.toLowerCase(Locale.ROOT);
+  }
+
+  /**
+   * Validates a candidate target URL.
+   *
+   * @param url the URL submitted by the client
+   * @return the trimmed URL, safe to store and redirect to
+   * @throws InvalidLinkRequestException if the URL violates the policy
+   */
+  public String validate(String url) {
+    if (url == null || url.isBlank()) {
+      throw reject("must not be blank");
+    }
+    String candidate = url.strip();
+    if (candidate.length() > MAX_LENGTH) {
+      throw reject("must be at most " + MAX_LENGTH + " characters");
+    }
+    URI uri = parse(candidate);
+    String scheme = uri.getScheme();
+    if (scheme == null || !ALLOWED_SCHEMES.contains(scheme.toLowerCase(Locale.ROOT))) {
+      throw reject("must be an absolute http or https URL");
+    }
+    String host = uri.getHost();
+    if (host == null || host.isBlank()) {
+      throw reject("must contain a valid host");
+    }
+    if (uri.getRawUserInfo() != null) {
+      throw reject("must not contain user info");
+    }
+    if (ownHost != null && ownHost.equals(host.toLowerCase(Locale.ROOT))) {
+      throw reject("must not point at this shortener");
+    }
+    return candidate;
+  }
+
+  private static URI parse(String candidate) {
+    try {
+      return new URI(candidate);
+    } catch (URISyntaxException e) {
+      throw reject("is not a valid URL");
+    }
+  }
+
+  private static InvalidLinkRequestException reject(String message) {
+    return new InvalidLinkRequestException(FIELD, message);
+  }
+}

+

+      }
+    }

+
+import com.github.benmanes.caffeine.cache.Cache;
+import com.github.benmanes.caffeine.cache.Caffeine;
+import io.github.marishasahay.shortener.config.ShortenerProperties;

+/**
+ * In-memory, per-client token-bucket rate limiter.
+ *
+ * <p>Buckets live in a size-bounded Caffeine cache so memory cannot grow without limit. A bucket
+ * idle for a full period would be full again anyway, so expiring it after that much inactivity
+ * loses no state. The limit is per instance; a multi-instance deployment needs a shared store.
+ */
+public class RateLimiter {
+
+  private final int capacity;
+  private final long periodMillis;
+  private final Clock clock;
+  private final Cache<String, TokenBucket> buckets;
+
+  /**
+   * Creates a rate limiter.
+   *
+   * @param settings capacity, refill period and the maximum number of tracked clients
+   * @param clock time source used for refill
+   */
+  public RateLimiter(ShortenerProperties.RateLimit settings, Clock clock) {
+    this.capacity = settings.requestsPerPeriod();
+    this.periodMillis = settings.period().toMillis();
+    if (capacity < 1 || periodMillis < 1) {
+      throw new IllegalArgumentException("rate limit capacity and period must be positive");
+    }
+    this.clock = clock;
+    this.buckets = Caffeine.newBuilder()
+        .maximumSize(settings.maxTrackedClients())
+        .expireAfterAccess(settings.period())
+        .build();
+  }
+
+  /**
+   * Takes one token from the client's bucket if available.
+   *
+   * @param clientKey identifies the client, e.g. its IP address
+   * @return whether the request is allowed and, if not, when to retry
+   */
+  public RateLimitDecision tryAcquire(String clientKey) {
+    long now = clock.millis();
+    TokenBucket bucket = buckets.get(clientKey,
+        key -> new TokenBucket(capacity, periodMillis, now));
+    return bucket.tryConsume(now);
+  }

+package io.github.marishasahay.shortener.ratelimit;
+
+import java.time.Duration;
+
+/**
+ * A single client's token bucket with continuous refill. To keep refill exact without floating
+ * point, one token is represented as {@code periodMillis} units: every elapsed millisecond adds
+ * {@code capacity} units, so a full period adds exactly {@code capacity} tokens.
+ */
+final class TokenBucket {
+
+  private final long capacity;
+  private final long periodMillis;
+  private final long maxUnits;
+  private long units;
+  private long lastRefillMillis;
+
+  TokenBucket(int capacity, long periodMillis, long nowMillis) {
+    this.capacity = capacity;
+    this.periodMillis = periodMillis;
+    this.maxUnits = capacity * periodMillis;
+    this.units = maxUnits;
+    this.lastRefillMillis = nowMillis;
+  }
+
+  synchronized RateLimitDecision tryConsume(long nowMillis) {
+    refill(nowMillis);
+    if (units >= periodMillis) {
+      units -= periodMillis;
+      return RateLimitDecision.allow();
+    }
+    long missingUnits = periodMillis - units;
+    long waitMillis = Math.ceilDiv(missingUnits, capacity);
+    return RateLimitDecision.reject(Duration.ofMillis(waitMillis));
+  }
+
+  private void refill(long nowMillis) {
+    long elapsed = nowMillis - lastRefillMillis;
+    if (elapsed <= 0) {
+      return;
+    }
+    long boundedElapsed = Math.min(elapsed, periodMillis);
+    units = Math.min(maxUnits, units + boundedElapsed * capacity);
+    lastRefillMillis = nowMillis;
+  }
+}

+package io.github.marishasahay.shortener.support;
+
+import java.time.Clock;
+import java.time.Duration;
+import java.time.Instant;
+import java.time.ZoneId;
+import java.time.ZoneOffset;
+
+/**
+ * A {@link Clock} whose time is set by the test, for deterministic time-dependent behaviour.
+ */
+public final class MutableClock extends Clock {
+
+  private volatile Instant instant;
+
+  public MutableClock(Instant instant) {
+    this.instant = instant;
+  }
+
+  public void setInstant(Instant instant) {
+    this.instant = instant;
+  }
+
+  public void advance(Duration duration) {
+    this.instant = instant.plus(duration);
+  }
+
+  @Override
+  public Instant instant() {
+    return instant;
+  }
+
+  @Override
+  public ZoneId getZone() {
+    return ZoneOffset.UTC;
+  }
+
+  @Override
+  public Clock withZone(ZoneId zone) {
+    throw new UnsupportedOperationException("MutableClock is always UTC");
+  }
+}
