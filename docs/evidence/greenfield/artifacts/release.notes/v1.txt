# URL shortener v1

Create, redirect, read and delete short links on PostgreSQL with abuse protection and an OpenAPI contract.

## Changes
- Link API and redirect
- URL and alias policies
- Per-client rate limit
- RFC 9457 errors
- Swagger UI on the checked-in contract

## Risks
- Management API is unauthenticated (gateway required)
- Rate limit and cache are per instance

## Rollback plan
New service: undeploy; V1 can be dropped with the database.

## Testing
Unit and Testcontainers integration tests; coverage gate.

## Follow-ups
- Authentication and link ownership
- Click analytics
