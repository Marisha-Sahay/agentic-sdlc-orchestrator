# Click analytics and cached-expiry fix

Best-effort click recording with per-link statistics, and expired links no longer redirect from cache.

## Changes
- link_clicks table (V2)
- Bounded asynchronous recording with counted drops
- GET /api/v1/links/{code}/stats
- 90-day retention purge
- Expiry checked on every cache hit (issue #1)

## Risks
- Clicks can be lost on saturation, failed batches or a crash (counted, documented)
- Statistics are unauthenticated (gateway required)

## Rollback plan
Revert the commit. V2 is additive: leave it, or drop table link_clicks after reverting.

## Testing
Unit tests for privacy reduction, saturation and flushing; Testcontainers ITs for statistics, retention, the expiry regression and contract conformance; final validation re-ran every check on the released tree.

## Follow-ups

- Durable click pipeline if exact counts become a requirement
