Implement click recording asynchronously using Spring's `@Async` with a `ThreadPoolTaskExecutor` configured with a bounded queue.		This choice directly addresses NFR-1 by decoupling click recording from the critical redirect path, ensuring minimal latency impact on redirects. Modify `LinkResolver` to store full `Link` objects (containing `expiresAt`) in the Caffeine cache. This choice directly addresses FR-3 and NFR-4 by ensuring that expired links consistently return HTTP 410 Gone, even when present in the cache. It centralizes the expiration logic within the `LinkResolver`, making it robust and easy to reason about.
