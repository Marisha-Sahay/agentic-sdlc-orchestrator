# Design

Store (targetUrl, expiresAt) in the redirect cache and re-check expiry on every lookup; add a partial index on links.expires_at via V2. No API change.

## Components

| Component | Responsibility | Files |
|---|---|---|
| LinkResolver | Resolve codes; enforce expiry on hit and miss | src/main/java/io/github/marishasahay/shortener/link/LinkResolver.java |
| CachedLink | Cache value with expiry | src/main/java/io/github/marishasahay/shortener/link/CachedLink.java |
| CacheConfiguration | Typed cache bean | src/main/java/io/github/marishasahay/shortener/config/CacheConfiguration.java |

## Data model

links: unchanged columns; new partial index idx_links_expires_at (expires_at) WHERE expires_at IS NOT NULL

## Decisions

### Where to enforce expiry

**Decision:** Re-check expiry on every lookup in LinkResolver, using the cached expiresAt

**Rationale:** Correct at the exact instant, O(1), no database access on hits

**Alternatives:** Per-entry Caffeine expiry (correct but relies on the cache ticker, not the application Clock, which makes it hard to test); Shorter TTL (reduces but does not remove the window)

### Schema change

**Decision:** New V2 migration with a partial index

**Rationale:** Applied migrations are immutable; partial index keeps it small

**Alternatives:** Full index on expires_at; Edit V1 (rejected: breaks Flyway checksums in existing environments)

### Deleted links in cache (FR-3, reviewer amendment)

**Decision:** Keep evict-on-delete; add a regression test

**Rationale:** LinkService.delete already evicts synchronously; the gap was missing test coverage, not behaviour

**Alternatives:** Tombstone entries in the cache

## Risks and trade-offs

- Clock skew across instances can shift expiry by the skew; acceptable
