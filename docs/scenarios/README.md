# Scenarios: what was run, and with which model

| Scenario | Model replies in the evidence | Reviewer in the evidence | Status |
|---|---|---|---|
| [greenfield](greenfield.md) | hand-authored fixtures (`cassettes/greenfield`) | scripted demonstration decisions | SUCCEEDED, release accepted on the validated tree |
| [brownfield](brownfield.md) | hand-authored fixtures (`cassettes/brownfield`) | scripted demonstration decisions | SUCCEEDED; its patch is the final service |
| [ambiguous](ambiguous.md) | hand-authored fixtures (`cassettes/ambiguous`) | scripted demonstration answers and decisions | SUCCEEDED |
| [drill](drill.md) | hand-authored fixtures with planted faults | scripted demonstration decisions | SUCCEEDED, 5 faults recovered |

**Provenance.** Every model reply in the committed evidence is hand-authored and labelled
`fixture:hand-authored` / mode `fixture` in the audit log; `./agentic check-evidence` prints the
counts. The fixtures are generated by [`tools/make-scenario-cassettes.py`](../../tools/make-scenario-cassettes.py)
and [`tools/make-drill-cassettes.py`](../../tools/make-drill-cassettes.py). The code they carry is
real and every line of it went through the run's policy, compile, test, integration-test,
Checkstyle, coverage, contract and docs gates; the greenfield output is byte-identical to
`url-shortener/` and the brownfield output to the final service. What the fixtures do **not** show
is how well a model performs these tasks.

**Reviewer provenance.** `--approvals scripted` applies decisions written in each scenario file.
They are recorded as `scripted-demo (scenarios/<name>.yaml)` and their comments say
"Demonstration decision"; no human reviewed these runs. Each decision covers named reasons only;
anything unforeseen pauses the run (fail closed).

**Live-model validation** is reported in [live.md](live.md).

**Reproduce:** `./agentic run <scenario> --approvals scripted` (about 35-40 s each with Docker),
then `./agentic publish-evidence <run-id> <scenario>` and `./agentic check-evidence <scenario>`.
Timings differ between runs; the path (attempts, approvals, checkpoints, patch) does not.
